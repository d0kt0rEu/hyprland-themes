# Obsidian Pink Cyberpunk Theme for JetBrains

A unified Obsidian Cyberpunk theme for all JetBrains IDEs (**CLion**, **RustRover**, **IntelliJ IDEA**, **PyCharm**, **WebStorm**, **GoLand**, etc.).

## Palette
- **Editor Background**: `#0f0c16` (Obsidian Black)
- **Tool Windows / Sidebar**: `#13101c`
- **Toolbars & Popups**: `#1a1528`
- **Neon Pink Accent**: `#ff2a85` (Keywords, caret, active tabs, buttons, focus)
- **Electric Purple Accent**: `#bd93f9` (Functions, types, classes, line numbers)
- **Foreground Text**: `#f1eef8`

## Included Files
- `ObsidianPinkTheme.jar`: Full UI theme plugin (menus, toolbars, sidebars, buttons, tabs).
- `Obsidian_Pink.icls`: Standalone Editor syntax color scheme (C/C++, Rust, Python, etc.).
- `install.sh`: One-click installer for all detected JetBrains IDEs.

## How to Apply in Any JetBrains IDE

### Method 1: Automatic Script
Run:
```bash
~/jetbrains-theme/install.sh
```

### Method 2: Install Plugin from Disk
1. Open your JetBrains IDE (RustRover, CLion, etc.).
2. Go to `Settings` (`Ctrl + Alt + S`) -> `Plugins`.
3. Click the ⚙️ gear icon -> **`Install Plugin from Disk...`**.
4. Select `~/jetbrains-theme/ObsidianPinkTheme.jar`.
5. Restart the IDE.
6. Under `Appearance & Behavior` -> `Appearance` -> `Theme`, choose **Obsidian Pink Cyberpunk**.
